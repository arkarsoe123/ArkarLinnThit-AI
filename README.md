# Arkar Lin Thit AI

## v1.6.0 — 99+ AI Assistant Upgrade

Arkar Lin Thit AI is a chat-first Android assistant designed to combine conversational AI with practical device tools.

### What is new in v1.6.0

- **129 ready-to-use AI Skills**: writing, translation, study, business, planning, coding, data, productivity, creativity and more.
- **AI Skill Library** with search and one-tap prompt launch.
- **Developer Mr.A** page inside the app.
- **Support / KPay** section with:
  - KPay number: `09691529743`
  - Copy number
  - Open KPay when installed
  - Share support information
- **AI provider foundation** for Mini Offline AI, Gemini, OpenAI-compatible endpoints, Anthropic, Ollama/Localhost and Custom API.
- **Safety-aware ToolExecutor** boundary for device actions.
- **Local MemoryManager** foundation; memory data remains in the app's private storage.
- Existing v1.5.1 chat-first UI is preserved: no bottom navigation bar, with New Chat, Tools and Settings at the top-right.
- Existing camera, music, gallery, timer, notes, spreadsheet, code studio, Wi-Fi/system and automation tools are retained.

### Important

Cloud AI features require the selected provider's own API configuration where applicable. API keys are not hard-coded into the source.

KPay support is user-controlled: the app can open the installed KPay app or copy/share the support number, but it does not silently perform or confirm a financial transfer.
